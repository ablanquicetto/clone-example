# Portafolio web — Santia Alfonso Blanquicett Teheran

## Descripción del proyecto

Este proyecto consiste en desarrollar un portafolio web para presentar el perfil profesional como desarrollador Full-Stack Junior, habilidades técnicas, proyectos destacados y medios de contacto.

## Objetivos

- Presentar el perfil profesional y la experiencia de la desarrollador.
- Mostrar las habilidades y herramientas relacionadas con el desarrollo web.
- Describir proyectos realizados y destacar sus logros.
- Facilitar el acceso al CV, GitHub, demostraciones de proyectos y datos de contacto.
- Construir una estructura preparada para adaptarse a diferentes tamaños de pantalla.

## Secciones del sitio web

### 1. Presentación

Contiene el nombre, el perfil profesional, una descripción del desarrollador y una fotografía.

El perfil destaca conocimientos de HTML, CSS, JavaScript y React, así como lógica básica de back-end y herramientas como Git, GitHub y Figma.

Incluye enlaces para descargar el CV, visitar GitHub y acceder a la sección de contacto.

### 2. Habilidades y herramientas

Presenta las tecnologías y herramientas relacionadas con el desarrollo web, entre ellas:

- HTML
- CSS
- JavaScript
- Git
- GitHub

La sección podrá ampliarse según las habilidades que se deseen mostrar en la versión definitiva del portafolio.

### 3. Proyectos destacados

Esta sección presenta proyectos formativos mediante tarjetas que incluyen imágenes, títulos, descripciones y enlaces.

**Proyecto: Página web de una cafetería**

El proyecto consiste en una landing page responsiva desarrollada a partir de un brief de diseño. Incluye estructura semántica, maquetación con Flexbox, creación de secciones y un formulario de contacto funcional.

Como logro, se destaca la implementación del diseño, la organización del código y la publicación mediante GitHub Pages.

Se contempla una segunda tarjeta para incorporar otro proyecto, con su correspondiente descripción, imagen y enlaces.

### 4. Contacto

Incluye una dirección de correo electrónico y enlaces a redes sociales.

## Tecnologías y técnicas

### HTML5

Se utiliza para definir la estructura semántica del sitio mediante elementos como:

- header: encabezado.
- nav: navegación principal.
- main: contenido principal.
- section: secciones del portafolio.
- article: tarjetas de proyectos.
- footer: pie de página.

### CSS3

Se utiliza para definir los estilos visuales, la distribución de los elementos, los colores, la tipografía, los espacios y los fondos.

### Flexbox

Se utiliza para alinear elementos y distribuir componentes como los enlaces de navegación, los botones y los grupos de enlaces.

### Gradientes CSS

Se utilizan fondos oscuros y degradados radiales de tonos púrpura para crear profundidad visual y destacar determinadas zonas del diseño.

### Diseño responsivo

Se utilizan medidas flexibles y herramientas CSS como min(), minmax(), aspect-ratio y media queries para adaptar la distribución del contenido a diferentes tamaños de pantalla.

### Accesibilidad básica

Se contempla el uso de etiquetas semánticas, atributos alt en las imágenes y nombres descriptivos para los enlaces.

## Requisitos de diseño responsivo

El proyecto completo se adapta a los siguientes anchos de referencia:

Resolución: Dispositivo de referencia

1440 px Escritorio
768 px Tableta
320 px Móvil

### Puntos de ruptura

Se utilizán los siguientes puntos de ruptura:

- 1023px: adaptación para tabletas y pantallas medianas.
- 767px: adaptación para dispositivos móviles.

### Resoluciones intermedias

Además de los tamaños de referencia, se comprueba el comportamiento del diseño en:

- 1500 px
- 1100 px
- 999 px
- 768 px
- 665 px
- 470 px
- 320 px

El objetivo es evitar desbordamientos horizontales, textos comprimidos, imágenes deformadas y elementos que se superpongan o pierdan su alineación.
