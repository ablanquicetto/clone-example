Proyectos

Calculadora interactiva

HTML CSS JavaScript

Desarrollo de una calculadora web interactiva con funcionalidades avanzadas, incluyendo un historial de operaciones.

Fue un proyecto personal diseñado para profundizar en la lógica de las operaciones matemáticas en JavaScript y la gestión del estado de la interfaz de usuario.

La interfaz de la calculadora es similar a la de un dispositivo físico. El diseño se construyó con Flexbox para el layout principal de los botones, asegurando una distribución uniforme y responsiva, mientras que también se usó para alinear el display de la calculadora y el área del historial.

La lógica de JavaScript fue el corazón del proyecto. Una de las características clave fue el historial de operaciones. Cada vez que se realiza un cálculo, la operación y su resultado se guardan y se muestran en un panel lateral.

Se prestó especial atención a la experiencia de usuario, haciendo que los botones sean visualmente interactivos. Además, la calculadora es completamente accesible mediante teclado, lo cual mejora su usabilidad.
